# Dominykas ir Viktorija – vestuvių kvietimas

## Paleidimas kompiuteryje
```bash
npm install
npm run dev
```

## Publikavimas per Vercel
1. Įkelkite visą aplanką į GitHub repozitoriją.
2. Vercel pasirinkite **Add New → Project**.
3. Importuokite GitHub repozitoriją.
4. Framework preset: **Vite**; Build command: `npm run build`; Output directory: `dist`.
5. Spauskite **Deploy**.

RSVP ir Google Maps nuorodos jau įrašytos faile `src/App.jsx`.
